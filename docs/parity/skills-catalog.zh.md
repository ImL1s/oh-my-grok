## Host-native 保护

这些名字不能成为 Grok 插件目录，也不能静默替换宿主 slash 命令：

`agents`, `compact`, `goal`, `help`, `loop`, `mcp`, `plan`, `plugin`, `skills`

`plan` 与 `goal` 仅为 **别名**（`host_native_protected`），解析到 `omg-ralplan` / `omg-ultragoal`。

## 续跑权

同时只能有一个：`omg-autopilot`, `omg-pipeline`, `omg-ralph`, `omg-ralplan`, `omg-team`, `omg-ultragoal`, `omg-ultraqa`, `omg-ultrawork`

冲突解析为 `refuse`、`adopt_existing` 或 `artifact_only`。cancel/using 一律 adopt。循环进行中 wiki/HUD/LSP/ask 仅写制品。
