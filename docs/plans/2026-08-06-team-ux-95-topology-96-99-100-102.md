# Team UX Topology — #96 (this PR) + follow-ups

> **PR #107 scope:** issue **#96 only** (same-window Team topology).
> Issues **#99** (provider-ready), **#100** (silent bootstrap), and **#102**
> (full scale UX) remain follow-ups — do not ship them on this PR.

**Plan token:** `OMG96-PLAN-TOKEN: OMG96-PLAN-1786065466`

**Goal (#96):** Inside-tmux Team launch defaults to `same_window` (leader left,
workers stacked right), persists `view_mode`, restores/verifies the exact
leader, uses `main-vertical` with clamped width, and never kill-windows the
shared leader window on rollback/stop. `--dedicated-window` keeps the legacy
dedicated Team window; outside tmux records `detached_session`.

**Non-goals for this PR:** provider-ready (#99), silent bootstrap (#100), full
scale UX beyond the minimum topology-respecting scale/resume/stop paths
required so new same_window runs do not destroy the leader (#102 remainder).

**Depends on:** `origin/main` foundations (#97/#98/#108) — WAL, server
identity, TMUX_PANE bind, absence-proof cleanup.

### #96 acceptance (this PR)

| Item | Behavior |
|------|----------|
| Default inside | `view_mode=same_window`; no `new-window` |
| First worker | `split-window -h -d -t <leader_pane>` |
| Later workers | `split-window -v -d -t <worker_stack_pane>` |
| Layout | `main-vertical` + clamped `main-pane-width` |
| Leader | restore + prove pane/pid/session/window + `pane_active=1` |
| Opt-in | `--dedicated-window` (inside only; fail closed with `--detach`) |
| Outside | `detached_session` |
| Persist | plan-only / dry-run / live JSON carry `view_mode` (+ layout) |
| Legacy | missing `view_mode` → dedicated/detached read path (never guess same_window) |
| Rollback/stop | same_window: scoped pane cleanup only; never kill leader window/session |
| Scale/resume | read persisted `view_mode`; same_window scale uses vertical splits |
